Chapter 08 第八章 · 窓

공정 창과 CD 균일도

실험실에서 한 번 예쁜 무늬를 찍는 것과, 하루 수천 장의 웨이퍼 위 수천억 개 선을 모두 규격 안에 찍는 것은 전혀 다른 일이다. 초점은 웨이퍼 평탄도와 렌즈 열 변형으로 ±수십 nm 흔들리고, 노광량은 광원과 감광액 두께로 ±몇 % 흔들린다. 이 흔들림을 모두 견디는 영역이 공정 창(process window)이다. 이 장에서는 보썽 곡선을 그리고, 촘촘한 선과 외딴 선이 함께 살 수 있는 공통 공정 창을 찾고, 여러 오차원이 쌓여 만드는 CD 균일도(CDU) 예산을 몬테카를로로 계산한다.

  • 초점·노광량에 따른 CD 변화(보썽 곡선)를 계산하고, 촘촘한 선과 외딴 선의 최적 초점·노광 차이를 본다.
  • 노광량–초점(ED) 창에서 노광 관용도(EL)와 초점 심도(DOF)의 맞바꿈 곡선을 읽는다.
  • 여러 패턴의 공정 창을 겹쳐 공통 창을 찾고, 외딴 선 바이어스로 창을 넓힌다.
  • 노광량·초점·마스크·PEB·확률적 요동의 기여를 제곱합으로 쌓아 CDU 예산을 세운다.

01보썽 곡선: 초점과 노광량의 지도

여러 초점(가로)과 노광량(곡선별)에서 CD를 측정해 그린 그래프가 보썽 곡선이다(1960년대 IBM의 John Bossung이 처음 그렸다). 곡선이 평평한 초점이 최적 초점이고, 노광량이 바뀌어도 CD가 그대로인 초점이 생기면 그곳을 등초점(isofocal)이라 한다. 촘촘한 선과 외딴 선은 회절 차수 분포가 달라 같은 노광량에서 CD가 다르고(iso–dense 바이어스), 보썽 곡선의 휘는 방향과 정도도 다르다.

$$CD(E, z) \approx CD_0 + \frac{\partial CD}{\partial E}(E - E_0) + \frac{1}{2}\frac{\partial^2 CD}{\partial z^2}(z - z_0)^2 + \dots$$

초점 0, 기준 노광의 CD (촘촘 / 외딴)
iso–dense 바이어스

읽는 법. 목표 CD 50 nm(트렌치, 감광액이 녹는 곳). 실선 = 촘촘한 트렌치(피치 100 nm), 점선 = 외딴 트렌치(피치 400 nm). 색은 노광량(파랑 −6 %, 남색 −3 %, 빨강 기준, 노랑 +3 %, 초록 +6 %). 초록 띠는 목표 ±10 %. 외딴 트렌치는 같은 노광에서 더 좁게 찍히고(환형 조명에서는 아예 열리지 않고) 초점에 더 민감하다. 마스크 바이어스를 주어 두 패턴을 맞춰 보자.

02ED 창과 공통 공정 창

보썽 곡선을 뒤집어 보면, 노광량–초점 평면에서 CD가 규격 안에 드는 영역이 생긴다. 이 영역 안에 넣을 수 있는 직사각형(또는 타원)의 높이가 노광 관용도(EL), 폭이 초점 심도(DOF)다. 직사각형을 납작하게 하면 DOF가 늘고 EL이 줄어든다. 이 맞바꿈을 그린 것이 EL–DOF 곡선이다. 한 층에는 여러 패턴이 있으므로 모든 패턴의 창이 겹치는 공통 창이 실제 공정 창이다. 보통 "EL 5 %에서 DOF ≥ 80 nm" 같은 기준을 쓴다.

實驗실험 8-2공정 창 겹치기
촘촘 DOF @ EL
외딴 DOF @ EL
공통 DOF @ EL

읽는 법. 왼쪽: 가로 = 초점(−150 ~ +150 nm), 세로 = 노광량(기준 대비 −15 ~ +15 %). 파랑 = 촘촘한 선만 규격 안, 노랑 = 외딴 선만, 초록 = 둘 다(공통 창). 빨간 직사각형은 요구 EL에서 가장 넓은 DOF. 오른쪽: EL–DOF 맞바꿈 곡선(파랑 촘촘, 노랑 외딴, 초록 공통).

🎯바람 부는 날의 양궁과녁 한가운데(목표 CD)를 맞히는 것보다 중요한 것은, 바람(초점)과 활 당기는 힘(노광량)이 조금씩 달라져도 여전히 과녁 안에 들어가는 것이다. 공정 창은 "얼마나 흔들려도 괜찮은가"의 지도이고, 엔지니어는 과녁 중앙이 아니라 창의 한가운데를 겨눈다.

03CD 균일도 예산

웨이퍼 전체의 CD 분포 폭(3σ)을 CDU라 한다. 서로 독립인 오차원들은 제곱합(root-sum-square)으로 쌓인다. 노광량 흔들림은 EL 기울기로, 초점 흔들림은 보썽 곡선의 휨으로, 마스크 CD 오차는 MEEF로, PEB 온도 오차는 감광액 민감도로 CD에 옮겨진다. 여기에 EUV 시대에는 광자 수 요동에서 오는 국부 CDU(LCDU)가 더해진다. 각 항이 CDU에 얼마나 기여하는지 알아야 어디에 돈을 쓸지(더 평평한 척, 더 좋은 마스크, 더 많은 노광량) 결정할 수 있다.

$$\sigma_{CD}^2 = \Bigl(\frac{\partial CD}{\partial E}\sigma_E\Bigr)^2 + \Bigl(\frac{\partial^2 CD}{\partial z^2}\Bigr)^2\frac{\sigma_z^4}{2} + \Bigl(\frac{MEEF}{4}\sigma_{mask}\Bigr)^2 + \Bigl(\frac{\partial CD}{\partial T}\sigma_T\Bigr)^2 + \sigma_{LCDU}^2$$

CDU 3σ (몬테카를로)
평균 CD 이동 (초점 휨 때문)
규격(±10 %) 안 비율
가장 큰 기여

읽는 법. 왼쪽: 5,000개 선의 CD 분포. 초록 띠는 규격(20 ± 2 nm). 초점 오차는 CD를 한쪽으로만(보썽 곡선이 아래로 휘므로 작게) 밀어 분포가 비대칭이 된다. 오른쪽: 오차원별 분산 기여(%). 가정한 민감도: 노광량 1 %당 −0.5 nm, 초점 휨 −0.0015 nm/nm², PEB 2 nm/°C.

생각해 보기. 노광량을 두 배로 높이면 처리량은 떨어진다. 그런데도 EUV 공정에서 노광량을 높이는 이유는?

광자 수가 두 배가 되면 샷 노이즈가 √2배 줄어 LCDU와 확률적 결함이 줄어든다. 위 예산에서 LCDU가 가장 큰 기여라면, 노광량을 올리는 것이 다른 어떤 개선보다 효과적일 수 있다. 결국 처리량(원가)과 수율 사이의 맞바꿈이다.

問확인 문제

보썽 곡선에서 노광량이 달라도 CD가 거의 같은 초점을 무엇이라 하는가?

  1. 최적 노광
  2. 등초점(isofocal) 지점
  3. 금지 피치
  4. 스윙 최소

등초점 근처에서 공정하면 노광량 흔들림에 둔감해진다.

공통 공정 창(common process window)이란?

  1. 가장 촘촘한 패턴의 공정 창
  2. 모든 웨이퍼의 평균 공정 창
  3. 스캐너가 허용하는 초점 범위
  4. 한 층의 모든 패턴의 공정 창이 겹치는 영역

한 번의 노광으로 모든 패턴을 함께 찍으므로 실제로 쓸 수 있는 창은 교집합이다.

서로 독립인 CD 오차원 1.2 nm, 0.9 nm(3σ)를 합친 CDU는?

  1. 1.5 nm
  2. 2.1 nm
  3. 1.05 nm
  4. 0.3 nm

제곱합: √(1.2² + 0.9²) = 1.5 nm.
