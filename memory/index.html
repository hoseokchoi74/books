What memory does

메모리는 무엇을 하는가

한 문장으로: 두 가지 이상 구별되는 물리 상태를 만들고, 원할 때 바꾸고, 바꾸지 않는 동안 유지하고, 상태를 망가뜨리지 않고 읽는다. 이 네 동사(만들기·쓰기·유지·읽기)를 어떤 물리로 해내느냐가 메모리 기술의 전부입니다. 블록을 누르면 해당 장으로 갑니다.
