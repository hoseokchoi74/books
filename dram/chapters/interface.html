Chapter 07 第七章 · 速

인터페이스: SDRAM에서 DDR5까지

셀 어레이는 20년 동안 거의 빨라지지 않았는데, DRAM 칩이 내보내는 데이터 속도는 수십 배가 되었다. 비결은 안쪽에서 넓게 읽어 바깥에서 빠르게 내보내는 것 — 프리페치와 직렬화다. 이 장은 클록의 양쪽 모서리, 버스트, 뱅크 그룹, 그리고 모바일·그래픽용 변종들을 다룬다.

  • SDR과 DDR의 차이, 데이터 스트로브(DQS)의 역할을 파형으로 설명할 수 있다.
  • 프리페치 \(n\)과 코어 주파수, 인터페이스 속도의 관계를 계산한다.
  • 모듈 대역폭 = 전송률 × 버스 폭 공식을 쓰고, DDR4와 DDR5 DIMM 구조 차이를 안다.
  • 뱅크 그룹이 tCCD_S/tCCD_L을 통해 대역폭에 미치는 영향을 이해한다.
  • LPDDR·GDDR·HBM이 각각 무엇을 위해 무엇을 포기했는지 비교할 수 있다.
  • 아이 다이어그램으로 신호 품질과 등화(equalization)의 필요성을 확인한다.

01클록의 양쪽 모서리

1990년대 중반의 SDRAM(Synchronous DRAM)은 시스템 클록에 맞춰 명령과 데이터를 주고받기 시작했다. 클록이 올라가는 모서리(상승 에지)마다 데이터 한 비트. 2000년 무렵의 DDR(Double Data Rate)은 내려가는 모서리(하강 에지)에서도 데이터를 보낸다. 같은 클록으로 두 배의 데이터. 그래서 "DDR5-4800"의 4800은 클록 주파수(2400 MHz)가 아니라 초당 전송 횟수(MT/s, mega-transfers per second)다.

속도가 올라가면 데이터가 도착하는 시점이 선마다 조금씩 어긋난다. 그래서 DDR은 데이터와 함께 DQS(data strobe)라는 별도의 "박자 신호"를 같이 보낸다. 받는 쪽은 시스템 클록이 아니라 DQS의 모서리에 맞춰 데이터를 샘플링한다.

02프리페치: 안에서 넓게, 밖에서 빠르게

셀 어레이와 열 경로는 수백 MHz 정도로밖에 돌지 못한다. 그런데 바깥 핀은 수 GHz로 데이터를 내보낸다. 이 차이를 메우는 방법이 n-비트 프리페치다. RD 명령 한 번에 어레이에서 핀당 \(n\)비트를 한꺼번에 병렬로 꺼낸 뒤, 직렬화기(serializer)로 줄 세워 빠르게 내보낸다. 이 \(n\)비트 묶음이 곧 버스트 길이(BL)다.

$$\text{코어 주파수} = \frac{\text{전송률}}{n_{prefetch}}, \qquad \text{예: DDR5-6400} \Rightarrow \frac{6400}{16} = 400\ \text{MHz}$$

그림 설명. 왼쪽 어레이가 코어 클록 한 번에 n비트를 병렬로 내놓으면, 오른쪽 직렬화기가 그것을 핀 하나로 줄 세운다. 코어는 그대로인데 n을 2배로 할 때마다 핀 속도도 2배가 된다. 대신 한 번에 꺼내는 양(접근 단위)도 커진다. DDR5가 BL16에서 64바이트 캐시 라인을 맞추기 위해 채널을 32비트 두 개로 쪼갠 이유다.

03대역폭 계산

$$\text{대역폭 [GB/s]} = \frac{\text{전송률 [MT/s]} \times \text{버스 폭 [bit]}}{8 \times 1000}$$
DDR5-6400 DIMM 하나(데이터 64비트) = 6400 × 64 / 8000 = 51.2 GB/s. 서버 CPU는 이런 채널을 8–12개 가진다.

04뱅크 그룹: 빠른 길과 느린 길

DDR4부터 뱅크는 뱅크 그룹으로 묶인다. 그룹 안의 뱅크들은 칩 안쪽의 데이터 경로(글로벌 I/O)를 공유하므로, 같은 그룹에 연속으로 RD를 보내면 tCCD_L(long)만큼 기다려야 한다. 다른 그룹이면 경로가 달라 tCCD_S(short)만에 다음 RD가 가능하다. 그래서 컨트롤러는 연속된 요청을 서로 다른 뱅크 그룹으로 흩뿌린다.

05신호 품질: 아이 다이어그램

수 Gb/s에서 PCB 배선은 더 이상 단순한 전선이 아니다. 고주파 성분이 더 많이 감쇠해 앞 비트의 잔상이 다음 비트에 번지는 심볼 간 간섭(ISI)이 생기고, 이웃 선의 크로스토크와 전원 잡음이 겹친다. 수많은 비트의 파형을 한 UI 폭에 겹쳐 그리면 눈 모양이 나타나는데, 이 아이(eye)가 열려 있어야 수신기가 0과 1을 가를 수 있다. DDR5는 이를 위해 수신단에 DFE(결정 궤환 등화기)를 넣었다.

問확인 문제

DDR5-5600에서 클록 주파수는?

  1. 5600 MHz
  2. 2800 MHz
  3. 1400 MHz
  4. 350 MHz

DDR은 클록 한 주기에 두 번 전송한다. 5600 MT/s ÷ 2 = 2800 MHz. (코어는 5600/16 = 350 MHz)

DDR5-6400 DIMM(데이터 64비트) 하나의 최대 대역폭은?

  1. 6.4 GB/s
  2. 25.6 GB/s
  3. 51.2 GB/s
  4. 409.6 GB/s

6400 × 64 / 8 = 51,200 MB/s.

프리페치 n을 늘리는 것의 대가는?

  1. 최소 접근 단위(버스트 크기)가 커진다
  2. 셀 커패시턴스가 줄어든다
  3. 리프레시가 더 자주 필요하다
  4. CL이 클록 수로 줄어든다

한 번 RD에 핀당 n비트가 나오므로 접근 단위가 커진다. 그래서 DDR5는 채널을 32비트 두 개로 나눠 BL16 × 32비트 = 64바이트를 맞췄다.

같은 뱅크 그룹에 연속 RD를 보낼 때 더 오래 기다려야 하는 이유는?

  1. 리프레시 때문에
  2. 셀이 파괴적으로 읽히기 때문에
  3. tFAW 때문에
  4. 그룹 내부의 데이터 경로를 공유해 tCCD_L이 적용되기 때문에

다른 그룹은 경로가 분리되어 tCCD_S만 지키면 된다.
