What DRAM does

DRAM은 무엇을 하는가

한 문장으로: 전하를 담아 두고, 새기 전에 다시 채우고, 필요할 때 증폭해 꺼낸다. CPU의 읽기 요청 하나가 셀까지 내려갔다 돌아오는 길이 곧 이 교과서의 목차입니다. 블록을 누르면 해당 장으로 갑니다.

DRAM in numbers

숫자로 보는 요즘 DRAM

이 책을 덮을 즈음이면 아래 숫자가 왜 중요한지, 서로 어떻게 얽혀 있는지 설명할 수 있게 됩니다. (수치는 2025–26년 양산 제품 기준의 대략값입니다.)

~10 fF셀 하나의 커패시턴스. 전자 약 3만 개 남짓을 담는다 → 2·3장
32 msDDR5의 리프레시 윈도. 모든 행을 이 안에 한 번씩 다시 채운다 → 3장
~100 mV전하 공유 후 비트라인에 생기는 신호. 센스 앰프가 이를 1.1 V로 키운다 → 4장
8,800 MT/sDDR5 핀 하나의 전송률. 클록 한 주기에 두 번 데이터를 보낸다 → 7장
60 : 1 +셀 커패시터의 종횡비. 지름 수십 nm, 높이 1 µm를 넘는 기둥 → 9장
2 TB/sHBM4 스택 하나의 대역폭. 2048비트 버스를 TSV로 쌓아 만든다 → 12장
