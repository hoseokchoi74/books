Chapter 12 第十二章 · 設

SoC 설계 놀이터

이제 직접 SoC를 기획해 보자. 공정을 고르고, 코어와 GPU·NPU를 몇 개 넣을지 정하고, 캐시와 메모리를 붙인다. 넣을수록 성능은 오르지만 다이가 커져 원가가 오르고, 최고 전력이 열 예산을 넘으면 지속 성능은 그만큼 오르지 않는다. 1–11장의 모델을 하나로 엮은 설계실이다.

  • 블록 구성이 다이 면적·원가·전력·성능에 미치는 영향을 한 번에 체험한다.
  • 열 예산 안에서 "최고 성능"과 "지속 성능"이 갈리는 지점을 찾는다.
  • 플래그십·중급·저가 SoC가 왜 다르게 구성되는지 이해한다.

모델 요약. 블록 면적(3 nm 기준): 성능 코어 3 mm², 효율 코어 0.6, GPU 코어 1.2, NPU 1 TOPS당 0.25, SLC 1 MB당 0.5, 메모리 PHY 32비트당 6, 기타(ISP·모뎀·I/O) 35 mm². 공정별 로직 밀도·전력·웨이퍼 가격·결함 밀도가 다르다(10장 원가 모델). 지속 성능 = 최고 성능 × min(1, 예산/최고 전력)^0.4 (DVFS로 전력을 줄일 때 성능은 덜 준다, 7장). 메모리 대역폭이 부족하면 GPU·NPU 성능이 깎인다(6장).

02도전 과제

설계 미션
  1. 보급형: 다이 원가 $15 이하로 CPU 점수 4 이상.
  2. 플래그십: 5 W 예산에서 GPU 지속 성능 5 이상, 다이 100 mm² 이하.
  3. AI 노트북: NPU 지속 80 TOPS 이상, 메모리 대역폭 부족 없이.
  4. 균형: 레이더의 여섯 축이 모두 절반 이상.

問생각해 볼 문제

GPU 코어를 두 배로 늘렸는데 지속 성능이 거의 그대로였다. 가장 그럴듯한 이유는?

  1. 캐시가 너무 커서
  2. 공정이 너무 새로워서
  3. 열 예산과 메모리 대역폭이 병목이라서
  4. NPU가 없어서

최고 전력이 예산을 넘으면 주파수를 낮춰야 하고, 대역폭이 모자라면 연산기가 기다린다.

보급형 SoC가 성능 코어를 적게 넣는 주된 이유는?

  1. 성능 코어가 면적을 많이 차지해 다이 원가를 크게 올리기 때문에
  2. 성능 코어가 느려서
  3. 소프트웨어가 지원하지 않아서
  4. 열이 너무 적게 나서

면적은 원가에 비선형으로 작용한다(10장).
