클록, 타이밍, 클록 도메인

디지털 회로는 클록이라는 박자에 맞춰 춤을 춘다. 박자마다 플립플롭이 값을 받아 두고, 그 사이에 조합 논리가 다음 값을 계산한다. 계산이 다음 박자 전에 끝나지 않으면(셋업 위반), 혹은 너무 빨리 바뀌면(홀드 위반) 틀린 값이 잡힌다. SoC에는 이런 박자가 수십 개 따로 돈다. 이 장은 타이밍의 규칙과, 서로 다른 박자 사이로 신호를 넘기는 위험한 다리 — 클록 도메인 교차 — 를 다룬다.

  • 셋업·홀드 조건과 타이밍 여유(slack)를 계산할 수 있다.
  • 클록 스큐가 셋업과 홀드에 반대 방향으로 작용함을 이해한다.
  • 클록 트리 균형과 편차가 스큐를 만드는 원리를 안다.
  • 메타스테빌리티와 동기화기의 MTBF를 계산한다.
  • PLL로 기준 클록에서 원하는 주파수를 만드는 원리를 안다.

01셋업과 홀드

플립플롭 A가 클록 모서리에 값을 내보내면(지연 \(t_{cq}\)), 조합 논리를 거쳐(\(t_{logic}\)) 플립플롭 B에 도착한다. B는 다음 클록 모서리보다 셋업 시간 \(t_{su}\) 전에 값이 안정되어 있어야 하고, 모서리 이후 홀드 시간 \(t_h\) 동안 값이 바뀌면 안 된다. B의 클록이 A보다 \(t_{skew}\) 늦게 도착하면 셋업에는 유리하고 홀드에는 불리하다.

$$\text{셋업 여유} = T_{clk} + t_{skew} - (t_{cq} + t_{logic} + t_{su}) \ge 0,\qquad \text{홀드 여유} = t_{cq} + t_{logic,min} - (t_h + t_{skew}) \ge 0$$

02클록 트리와 스큐

클록 신호는 칩 한가운데 PLL에서 출발해 수십만~수백만 개의 플립플롭에 동시에 도착해야 한다. 버퍼를 대칭으로 갈라 붙인 H-트리는 모든 경로의 길이를 같게 만든다. 그래도 공정 편차로 버퍼 지연이 조금씩 달라 도착 시간이 어긋난다(스큐). 클록 트리는 칩 동적 전력의 30 % 가까이를 쓰기도 해, 쓰지 않는 블록의 클록을 끊는 클록 게이팅이 중요하다.

03메타스테빌리티와 동기화기

서로 무관한 두 클록 사이로 신호를 넘기면, 신호가 언젠가는 받는 쪽 플립플롭의 셋업·홀드 창 안에서 바뀐다. 그러면 플립플롭은 0도 1도 아닌 중간 전압에서 한동안 머뭇거린다(메타스테빌리티). 머뭇거림은 시간이 지나면 지수적으로 풀리므로, 플립플롭 두세 개를 줄지어 두고 한 클록씩 기다리게 하는 동기화기로 위험을 원하는 만큼 줄인다.

$$\text{MTBF} = \frac{e^{\,t_r/\tau}}{T_0\, f_{clk}\, f_{data}},\qquad t_r \approx (N_{stage}-1)\,T_{clk} - t_{su}$$

04PLL: 원하는 주파수 만들기

SoC에는 보통 수정 발진기 하나(예: 38.4 MHz)만 있다. 수 GHz의 CPU 클록, 정확히 맞춰야 하는 화면·오디오·USB 클록은 모두 PLL(위상 고정 루프)이 만든다. PLL은 전압 제어 발진기(VCO)의 출력을 N으로 나눠 기준 클록과 위상을 비교하고, 차이가 0이 되도록 VCO를 조절한다. 결과적으로 \(f_{out} = f_{ref}\times N / M\). N이 정수면 만들 수 있는 주파수가 띄엄띄엄하므로, 분수 N(fractional-N) PLL로 세밀하게 맞춘다.

읽는 법. 위상 비교기(PFD) → 루프 필터(LPF) → VCO → 출력 분주기(÷M)로 이어지고, VCO 출력을 ÷N으로 나눠 되먹인다. VCO는 2–5 GHz에서만 동작한다고 가정했다. 정수 N에서는 기준 클록 간격으로만 맞출 수 있어 오차가 수백 ppm까지 생기고, 분수 N은 ppb 수준까지 맞춘다(대신 분수 잡음을 처리해야 한다).

問확인 문제

T_clk = 500 ps, t_cq = 50, t_logic = 380, t_su = 30 ps, 스큐 0일 때 셋업 여유는?

  1. −40 ps
  2. 40 ps
  3. 120 ps
  4. 0 ps

500 − (50 + 380 + 30) = 40 ps.

홀드 위반을 클록 주파수를 낮춰 고칠 수 없는 이유는?

  1. 셋업과 같은 식이라서
  2. 전압 문제라서
  3. 스큐가 0이라서
  4. 홀드 조건에 클록 주기가 들어가지 않아서

같은 모서리에서 출발·도착하는 경로의 최소 지연 문제다. 지연 버퍼를 넣어 고친다.
