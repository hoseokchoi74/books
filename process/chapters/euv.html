EUV와 다중 패터닝

ArF 액침 노광의 한계는 피치 약 80 nm다. 그런데 2010년대 칩은 40 nm, 지금은 20 nm대 피치를 쓴다. 이 틈을 메운 것이 두 가지다. 하나는 한 층을 여러 번 나눠 찍거나 측벽(스페이서)을 이용해 피치를 절반·4분의 1로 쪼개는 다중 패터닝, 다른 하나는 파장 13.5 nm의 EUV다. 둘 다 새로운 적을 만들었다 — 층 사이 정렬 오차와 피치 흔들림, 그리고 빛 알갱이 수가 모자라서 생기는 확률적 결함.

  • LELE·SADP·SAQP로 피치를 쪼개는 과정을 단면으로 따라간다.
  • 정렬 오차와 스페이서 두께 오차가 만드는 피치 흔들림(pitch walking)을 계산한다.
  • EUV 광자 에너지가 커서 같은 노광량에 광자 수가 적다는 것과, 그로 인한 확률적 결함을 실험한다.
  • 오버레이 예산을 제곱합으로 쌓아 본다.

01측벽으로 피치 쪼개기: SADP와 SAQP

LELE(노광-식각-노광-식각)는 홀수 선과 짝수 선을 두 장의 마스크로 따로 찍는다. 간단하지만 두 번째 노광이 첫 번째와 어긋나면 선 간격이 그대로 틀어진다. SADP(자기 정렬 이중 패터닝)는 한 번 찍은 굵은 심(맨드릴) 양옆에 막을 고르게 입힌 뒤(ALD) 위아래만 깎아 측벽(스페이서)만 남기고, 심을 제거한다. 스페이서 두 줄이 생기니 피치가 절반이 되고, 정렬은 공정 자체가 보장한다. 이것을 한 번 더 하면 SAQP, 피치 4분의 1이다.

02피치 흔들림: 짝수 칸과 홀수 칸이 다르다

SADP에서 스페이서 사이의 간격은 두 종류다. 맨드릴이 있던 자리(심 간격)와 이웃 스페이서 사이의 자리(골 간격). 맨드릴 선폭이 목표보다 크거나 스페이서가 두꺼우면 두 간격이 서로 달라져 선이 짝을 지어 몰린다. 이것이 피치 흔들림(pitch walking)이다. LELE에서는 두 번째 노광의 정렬 오차가 그대로 간격 차이가 된다.

$$\text{SADP: } s_{core} = w_{mandrel},\quad s_{gap} = p_0 - w_{mandrel} - 2t_{spacer};\qquad \text{LELE: } s_{1,2} = \tfrac{p}{2} - w \pm \Delta_{OL}$$

03EUV와 광자 산탄 잡음

EUV 광자 하나의 에너지는 hc/λ = 92 eV로 ArF(6.4 eV)의 14배다. 같은 노광량(mJ/cm²)이면 광자 수가 14분의 1이다. 20 nm 콘택 구멍 하나에 떨어지는 광자가 수천 개뿐이면 푸아송 통계의 흔들림(√N)이 무시 못 할 크기가 되어, 어떤 구멍은 너무 작게, 드물게는 아예 안 뚫린다. 칩에 구멍이 수십억 개이므로 10⁻¹²의 확률도 문제가 된다. 노광량을 올리면 줄어들지만 처리량(시간당 웨이퍼)이 떨어진다 — EUV의 근본적 줄다리기다.

$$N_{photon} = \frac{\text{Dose}\times A}{h c/\lambda},\qquad \frac{\sigma_N}{N} = \frac{1}{\sqrt{N}}$$

모형. 구멍마다 흡수 광자 수를 푸아송 난수로 뽑고, 받은 에너지에 비례해 크기를 정했다(평균의 70 % 미만이면 막힘). 왼쪽: 40×40 구멍 지도(빨강 = 막힘, 크기 = 인쇄된 지름). 오른쪽: 광자 수 분포와 막힘 문턱. 막힘 확률은 정규 근사 꼬리로 계산. 처리량은 광원 출력이 일정할 때 노광량에 반비례한다고 보았다.

04오버레이 예산

층과 층의 정렬 오차(오버레이)는 여러 원인이 독립적으로 더해진다: 노광기 스테이지·렌즈, 웨이퍼 휨과 열 변형, 마스크 위치 오차, 측정 오차, 공정이 만든 비대칭. 독립 오차는 제곱합의 제곱근(RSS)으로 합친다. 최신 공정의 오버레이 허용치는 2 nm 안팎 — 원자 열 개 남짓이다.

$$OL_{total} = \sqrt{\textstyle\sum_i OL_i^2}$$

읽는 법. 막대 길이는 각 항목의 제곱(분산) 기여 비율이다. RSS에서는 가장 큰 항목 하나가 전체를 지배한다 — 작은 항목을 절반으로 줄여도 별 효과가 없고, 가장 큰 것을 줄여야 한다.

問확인 문제

SADP에서 스페이서 두 줄이 생기는 이유는?

  1. 두 번 노광해서
  2. 마스크가 두 장이라서
  3. 맨드릴 양쪽 벽에 막이 남아서
  4. 스페이서를 반으로 잘라서

맨드릴 하나의 왼쪽·오른쪽 측벽에 각각 스페이서가 생겨 선이 두 배가 된다.

같은 노광량에서 EUV 광자 수는 ArF의 약?

  1. 14배
  2. 1/14
  3. 같다
  4. 1/2

광자 에너지가 92 eV 대 6.4 eV로 14배이므로 개수는 1/14.

오버레이 항목이 3, 1, 1 nm일 때 RSS 합은 약?

  1. 5 nm
  2. 1.7 nm
  3. 4 nm
  4. 3.3 nm

√(9 + 1 + 1) = √11 ≈ 3.3 nm.
