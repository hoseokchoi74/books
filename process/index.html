The process loop

한 층을 만드는 고리

거의 모든 층은 같은 고리를 돈다: 증착 → 노광 → 식각 → (주입·열처리) → 세정 → CMP → 계측. 이 고리를 수십 바퀴 돌면 칩이 된다. 각 칸을 누르면 해당 장으로 갑니다.
